GESTÃO DE GASTOS — PRONTO PARA PUBLICAR

1. Entre em https://app.netlify.com/drop
2. Extraia este arquivo ZIP.
3. Envie a PASTA 'gestao-de-gastos-app' ou o conteúdo dela para o Netlify.
4. O Netlify criará um link.
5. Abra o link no Safari.
6. Toque em Compartilhar > Adicionar à Tela de Início.

IMPORTANTE:
- O arquivo principal agora se chama index.html.
- O aplicativo foi preparado para instalação como aplicativo web.
- O Supabase continua sendo usado para login e armazenamento dos dados.
